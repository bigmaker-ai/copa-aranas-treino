# Copa Aranãs · Treino do app

Cópia de **treino** do app da equipe da transmissão da Copa Aranãs. É a mesma tela do app do celular, mas
**nada aqui vai para a transmissão**: os dados são uma foto do sistema e cada toque só mostra o que
aconteceria no jogo de verdade.

Abra pelo celular: https://bigmaker-ai.github.io/copa-aranas-treino/
